# Numerical Toys

Small interactive demos for computational mathematics.

## Demos

- [Finite Difference Coefficient Generator](demos/fd-coefficients.html) — Compute finite difference coefficients for arbitrary stencils.
- [Euler Riemann Solver (Exact)](demos/euler-riemann-solver.html) — Interactive visualization of the exact solution of the Euler Riemann problem.
- [Three-Body Simulation](demos/three-body.html) — Numerical simulation of gravitational three-body dynamics.
- [ColorManager Palette Browser](demos/color-manager-browser.html) — Browse a large dataset of curated color palettes with interactive swatches and curves.
